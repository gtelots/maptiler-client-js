# GTEL Maps Client Changelog

## 1.0.0
### New Features
- Migrated configuration variable names from MapTiler to GTEL Maps.
- Updated the default API domain to GTEL Maps.
- Updated the default map styles to GTEL Maps.
- Changed API key authentication to use the `apikey` query parameter when calling APIs.

### Bug Fixes
None

### Others
- Discontinued service modules that call MapTiler APIs, as these APIs are not yet available in GTEL Maps.
